# 단백질 합성 모의실험 (protein-sim)

고등학교 진로선택 「생물의 유전」 웹 활동 — 교과서 66~67쪽 탐구(부록 138쪽 모형)의 인터랙티브 버전.

- **2단계 전사**: 주형 가닥 30칸에 A/U/G/C를 직접 채워 mRNA 완성. T 단추는 채워지지 않고 「RNA에는 타이민이 없다 → 유라실」 안내
- **📖 코돈표 64칸 내장**(교과서 62쪽과 같은 구조 — 칸마다 코돈 병기 · 세 축 이름 표기)
- **3단계 번역**: E·P·A 자리 라이보솜, tRNA 카드 9장 중 골라 도킹 → [🔗 펩타이드결합 만들고 라이보솜 이동] → 종결코돈에서 「결합할 tRNA가 없다」 발견 → 분리 연출
  - ★**앱이 답을 미리 알려 주지 않는다** — 아미노산 이름·안티코돈은 감추고 코돈만 제시하여 학생이 **코돈표로 직접 해독**하게 한다(못 찾을 때는 [💡 아미노산 확인하기])
- **4단계 정리하기**: 탐구 과정 ①~⑧을 전사/번역/해당 없음으로 분류·채점, 모범답안, 내가 만든 결과 대조
- 💡 더 해보기: mRNA 염기 하나를 바꾸는 **돌연변이 모드** — 침묵/아미노산 치환/조기 종결/개시코돈 파괴/종결코돈 소실 5종을 학생이 찾아낸다
